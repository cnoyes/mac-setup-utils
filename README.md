# mac-setup-utils

Personal utilities for setting up a new MacBook development environment.

## 📦 Contents

- `install_ds_utils.sh` – Shell script to install core data science tools (Homebrew, pyenv, VS Code, R, etc.)
- `detachpackages.R` – R script to detach all loaded packages (useful for resetting the R environment)
- `.vimrc` – Vim configuration for syntax highlighting, indentation, and programming enhancements
- `.zprofile` – Shell profile settings for Zsh (e.g., `PATH`, aliases, pyenv setup)
- `README.md` – This documentation
